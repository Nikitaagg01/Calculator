# Calculator App

A simple and responsive Calculator App built using **HTML, CSS, and JavaScript**.
This project performs basic arithmetic operations with a clean user interface and interactive functionality.

---

## 🚀 Features

* Addition, Subtraction, Multiplication, Division
* Responsive UI
* Clear button functionality
* Real-time display updates
* User-friendly design
* Keyboard-like calculator layout

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
